Ideas principales

HTML organiza el contenido

Con HTML puedo indicar qué parte es un título, un párrafo, una imagen o un menú.

CSS cambia la presentación

Con CSS puedo usar clases para aplicar un mismo estilo en varios elementos.

JavaScript agrega acciones

Con JavaScript se pueden validar datos y modificar el contenido mientras la página está abierta.
